# 🚀 AI-Powered Fraud Risk Intelligence Platform

## 📊 Project Overview

This project presents an end-to-end **Fraud Risk Intelligence Platform** that detects high-risk financial transactions using machine learning and provides AI-driven insights through an interactive Power BI dashboard.

The system integrates **data analysis, predictive modeling, and business intelligence** to support fraud detection and decision-making.

---

## 🧠 Key Features

* 🔍 Fraud detection using machine learning model
* 📊 Interactive Power BI dashboard (Desktop + Service)
* 🚨 AI-based dynamic alert system
* 📈 Advanced KPIs:

  * Fraud Risk Score
  * Fraud Severity Index
* 📊 Risk segmentation (High, Medium, Low)
* 🧾 AI explanation of fraud patterns

---

## 🛠️ Tech Stack

* **Python (Pandas, Scikit-learn)** – Data processing & ML model
* **Power BI (Desktop + Service)** – Dashboard & reporting
* **DAX** – Advanced KPI calculations
* **Google Drive** – Large file storage

---

## 📂 Project Workflow

1. Data is loaded and cleaned using Python
2. Machine learning model predicts fraud probability
3. Risk levels are assigned (High / Medium / Low)
4. AI logic generates insights and alerts
5. Power BI dashboard visualizes KPIs and patterns
6. Dashboard is deployed to Power BI Service
